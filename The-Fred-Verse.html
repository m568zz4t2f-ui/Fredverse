Red outlined circles are practice hazards. Teal circles help teammates. Guard or dodge telegraphs; your attacks never hurt another Fred. A downed Fred can be revived by a teammate holding E while still for 2.5 seconds. Solo defeat resets the practice so you can recover.

 DIRECT BROWSER-TO-BROWSER · 1–4 FREDS

Bring your variant.

Open the game on both devices on the same local network. No Python, accounts, relay, or short-code service. One browser hosts the shared simulation; keep it open and in the foreground.

Experimental: browser co-op needs testing on normal LAN devices. This build's cloud test browser blocks direct peer networking. Solo has passed the complete chapter test.

1 · Host: make an invite

Start or continue a game, then create one invite per friend. Send the entire code privately. Codes expire after two minutes before connection.

2 · Guest: answer an invite

Send the entire reply to the host and wait for them to accept it. The host owns your character save. This browser remembers its private rejoin key; fresh connection codes are required after disconnecting.

This uses local WebRTC candidates without STUN/TURN or automatic LAN discovery. Some networks and browsers block direct connections. If a downloaded file cannot connect, use the HTTPS-hosted game in current Chrome, Edge or Firefox. Different networks are not supported by this baseline. Never paste connection codes into public posts.

 TAKE A BREATHER

Paused.

Local saves stay in this browser and address. Export a backup to move devices or addresses. Imports resume at Alpha with health preserved; interrupted practice resets. Guest progress belongs to the host; guest-only export is unavailable.
