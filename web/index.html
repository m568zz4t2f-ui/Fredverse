First steps: find the remote beside the dorm TV, exit south, and follow the map to Darling Pavilion. Approach the practice marker and press E. All Freds in the gym must be ready; solo starts immediately.

Red outlined circles are practice hazards. Teal circles help teammates. Guard or dodge telegraphs; your attacks never hurt another Fred. A downed Fred can be revived by a teammate holding E while still for 2.5 seconds. Solo defeat resets the practice so you can recover.

 BETTER WITH MORE FREDS

Bring your variant.

Run python server.py on one computer. Connect everyone to the same local network. On each device, open the host computer’s LAN IP with port 8000 in a browser.

Example address format: http://192.168.x.x:8000. Use your host’s actual address. Allow inbound TCP 8000 on its local firewall.

To find hosts from another computer with this project: python server.py --discover. UDP 47654 discovery can be blocked by guest Wi-Fi; direct address joining still works.

The host saves all characters. This browser stores a private rejoin key for this host address. Reuse the same browser and address to keep your Fred. No internet, accounts, or cloud services are required.
