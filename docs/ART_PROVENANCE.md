# Art and font provenance

- `web/assets/fred-atlas-prepared.png` is a transparent prepared derivative of the user's inline Fred sprite sheet, made with the image generation/editing tool during this session. It is **not claimed pixel-identical** to the original PNG, which was not available as a downloadable file binding.
- The prepared image is 1602 × 982 RGBA with transparent background. It preserves the five ten-pose directional rows and three bottom crouch/downed poses, **53 frames total**. `fred-atlas.json` records frame rectangles measured from this image's alpha channel and visual row boundaries. Walking uses columns 2–7, idle column 0, strike column 8, and downed row 5 column 1. Left-facing directions mirror the corresponding right-facing frames. Do not infer additional named combat animations without inspecting the source.
- The game embeds this atlas. It is the default player and inventory portrait, not a user-upload-only preview. Shirt material tint gives MLB jerseys a red appearance while preserving the prepared face, hair, shading and remaining sprite pixels. Headphone overlays indicate equipped head gear. Final wearable artwork and every action animation are not complete.
- Faculty figures remain original placeholder pixel art, not representations of the user's Fred or verified professor likenesses. Environment and item icons are original procedural pixel drawings. Their layouts reference user-provided media; they are not extracted Google imagery or redistributed watermarked photographs.
- Pixelify Sans is from Google's official font repository, downloaded over verified HTTPS: `https://github.com/google/fonts/tree/main/ofl/pixelifysans`. `web/assets/fonts/PixelifySans.ttf` and its complete `OFL.txt` are included. The standalone HTML embeds both the font and the license text, so sharing the HTML does not require a font CDN or a separate download.
- Google Maps / Street View research is pending a network allowlist update. No Google imagery has been copied into the game, and no map accuracy claim is based on inaccessible Google pages.

If the original sprite PNG is provided, inspect its actual dimensions, alpha channel, frame boundaries and pose order before replacing the prepared asset/manifest. Do not silently claim a guessed grid is verified.
